# MIRACH 布局方案 v8.0（2026-10-06 · 三栏无标签 · 面板栏唯一多标签）

> 实现载体 = dockview-react（替换 flexlayout 0.11）。本文只写**语义**，
> flexlayout 时代的实现细节已归档 docs/history-flexlayout.md。

## 1. 三栏

| 栏 | 内容 | 标签 | 分栏 |
|----|------|------|------|
| 左栏 | logo 行 + 入口条 + 会话列表 | **无** | 可分栏 |
| 主栏 | 会话聊天（工作区名头 + 消息/composer） | **无** | 可分栏 |
| 面板栏 | 文件树 / 终端 / 预览 / 打开页 | **唯一多标签列** | 可分栏 |

- 左栏与主栏**没有页签**——面板页签不能拖入，会话页签不存在（会话经
  侧栏点击指派到主栏焦点格）。
- 面板栏是唯一有多标签的列：文件树/终端/预览以页签共存。
- 左栏与主栏**只能分栏**（并排/上下拆分），拆出的格通过侧栏指派会话。

## 2. 工作区名 = 容器子元素

主栏顶部的工作区名（cwd 末段）不再是宿主层叠片（ChatLabelOverlay 废除）
——它是主栏容器内的**常规子元素**（列头），随列渲染、随分栏各持一份。
样式 = 列头行：项目名（大字）+ 会话名（小字）。

## 3. 分栏语义

- 主栏分栏 = 拆出并列格；每个格绑定一个会话（侧栏点击指派到**焦点格**）。
- 会话切换 = 侧栏行点击；被切换的会话进入焦点格，原格内容被顶替。
- 面板栏分栏 = 文件树/终端各占一格（已有语义平移）。
- 关空收列（ZCode 原义）保留：格内最后一个实签关闭/拖走 → 格关闭。

## 4. 20px 贴边留白

对话列（或任何列）直接到软件边缘的一侧，列头/颜色层/内容同步内缩
20px——dockview 下按 panel 容器位置判定（逻辑平移，载体换 dockview API）。

## 5. dockview 映射

| 语义 | dockview API |
|------|------|
| 三栏布局 | fromJSON（grid: left | main | panels） |
| 面板栏多标签 | group 内多 panel（原生） |
| 主栏无标签 | leaf group 隐藏 tab 头（hideHeader 或单 panel 无 tab） |
| 分栏 | addPanel({ reference, direction }) |
| 会话指派 | panel.update({ params: { threadId } }) |
| 关空收列 | onDidRemove → 空组 removeGroup |
| 布局持久化 | toJSON / fromJSON（存储键 v9） |
| 语义校验 | onWillDrop / onDidDrop 拦截 |
