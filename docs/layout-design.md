## 1. 总布局：三栏

```
┌──────────────────────────────────────────────┐
│ 顶带（85px · 页签条/logo/双行块三栏信息位）        │
├────────┬──────────────────────┬──────────────┤
│        │                      │  面板页签组    │
│ 左侧栏  │  对话栏               │  （打开页…）   │
│        │ （主会话+多开会话页签）  ├──────────────┤
│        │                      │  终端（可关）   │
└────────┴──────────────────────┴──────────────┘
```

- **左侧栏**：单窗格 `leftrail`——内含**会话列表**与**机器人花名册**两个
  视图，点击顶带 **Mirach 文字**切换（文字有点击态）。**没有页签条**，
  因此没有页签拖出/拖入。顶带 = logo + Mirach 文字行。
- **对话栏**：页签组 = 主会话（workspace）+ 多开会话页签（session-N）。
  **页签即真会话**（§6）。
- **面板栏**（原右栏）：上下两行——上行 = 页签组（**打开页**〔默认激活〕
  / 文件树 / 检查 / 预览），下行 = **终端**（可关页签，独占一行）。

**位置身份固定**：左=最左、对话=中间、面板=最右。页签不可跨栏改列身份
（列 identity 不再推导，§3）。

## 2. 尺寸约束

| 栏 | 最小宽 | 最大宽 | 默认宽 |
|------|------|------|------|
| 左侧栏 | 240 | **420（唯一有上限的栏）** | 350 |
| 对话栏 | 395 | 无上限（吸收者） | 剩余 |
| 面板栏 | 240 | 无上限 | 700 |

- 分栏规则：**上下最多 2 行，且这 2 行不可再竖分；左右不限**。面板栏的
  「页签组 + 终端」即一个合法的两行结构；对话栏可在栏内左右分栏、或上下
  一层（共 2 行），2 行后不可再竖分。
- 每行最小高度：只保留标题条高度，无上限（终端行默认 20vh）。

## 3. 页签归属与拖拽规则

| 页签 | 能去哪 |
|------|------|
| 左栏 | **无页签**——Mirach 文字切换视图，拖入拖出均不存在 |
| 对话栏页签（workspace/session-N） | **只能在对话栏内**：条内重排、拖出分栏（左右不限/上下第 2 行）；拖入左栏/面板栏被拒 |
| 面板栏页签（open/files/review/preview/terminal） | **对话栏 + 面板栏**均可（无限制）：条内重排、跨栏移动、拖出分栏 |
| 会话行（左栏列表） | 拖到**对话栏页签条 = 在该分栏开出会话页签**（hermes stack 语义）；拖到**主会话页签 = 切换主会话**；其余落点 = 拒绝 |

- 拖拽引擎保留 pointer 会话机械层（4px 阈值/rAF 合帧/Esc 顶层中止/跟手
  克隆件 fl-drag-clone/吞合成 click）；投放合法区按**页签归属**过滤。
- 分栏上下限在投放判定时强制：目标列竖向已有 2 行 → 拒绝第 3 行。

## 4. 多开与会话模型（hermes 语义）

- **主会话标签（workspace）恒在、不可关闭**（无关闭钮）。
- **「+」= 新建会话并开出新页签**（绑定该会话 threadId）。
- **点击左栏会话行** = 该会话已开页签 → 置前；未开 → **装入主会话标签**
  （主区内容切到该会话，不开新签）。
- **拖会话行落对话栏页签条** = 开出该会话的页签（stack）；落主会话页签 =
  切换主会话。
- **关闭会话页签** = 只删投影，会话留在左栏（数据不删），可再从左栏点开/
  拖出。运行中会话关闭先弹确认（hermes 同）。
- 页签激活 = runtime 切到该页签绑定的 threadId（全局投影）。**边界**：
  并排两个对话分栏各显各的会话不支持（v1 单投影）。
- **多标签模式**：对话栏 ≥2 页签时页签条显示；单签（只有主会话）无条
  （双行块占顶带，同 v4 行为）。

## 5. 打开页（面板栏默认页签）

- 三个**全宽按钮**（ZCode home 按钮范式：图标 + 文字 + 快捷键提示位）：
  **文件树** / **终端** / **预览**。
- 文件树 → 开出/激活文件树页签；终端 → 开出/激活终端行（关闭后由此
  重开）；预览 → 开出/激活预览页签（无文件时显示空态引导）。
- 文件树页签点击文件 → 预览页签（现有 preview-opener 链复用）。
- 打开页不可关闭（面板栏页签组的常驻锚）。

---

## 6. 会话页签绑定

- 多开会话页签 id = `session-N`，**config 带 threadId**（tab.config）。
- 页签激活 → runtime `switchToThread(threadId)`；页签标题 = 会话显示名
  （sessionCatalog 单一真相源不变）。
- 主会话标签内容 = 当前激活会话（mainThreadId 投影，现状保留）。

---

## 7. 保留的能力

- 会话行上下排序（dnd-kit）+ 边缘自动滚；会话行跨面拖（§3）。
- 双行块（跟随激活对话页签）、主区颜色层、左栏 logo/Mirach 行。
- 页签拖出跟手克隆件（fl-drag-clone）；条内插入符重排预览。
- 双击分隔条回默认宽（按出厂树比例，无预设概念后 = 出厂布局）。
- 页签溢出总览菜单（cmdk）；关闭/关闭其他/关闭右侧右键项。
