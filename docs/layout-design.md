## 1. 总布局：五区

```
┌─────────────────────────────────────────────┐
│ 顶部标题栏（36px · 自绘 · 拖拽区）              │
├──────┬───────────────────────────┬──────────┤
│      │                           │          │
│ 左栏  │ 主栏（中间栏）              │ 右栏      │
│      │                           │          │
├──────┴───────────────────────────┴──────────┤
│ 底部栏（20px）                                │
└─────────────────────────────────────────────┘
```

三栏是**位置身份**：左栏=最左、主栏=中间、右栏=最右。主栏的**家**永远是
中间栏——右栏隐藏、被拖走、或不存在，都不改变这一点（§5 回家锚点据此
定义）。

**位置身份与列 identity 是两个概念**（v3.1 拆分）：列 identity（§2.1，
决定宽度限制）跟随内容；位置身份只决定"回家去哪"。一级窗格拖到别的列，
不改变那一列的 identity（§2.1 防重锚），只按所在列的限制走。

## 2. 列 identity 与宽度限制（**限制跟随状态**）

### 2.1 列的 identity 由锚定一级窗格决定（防重锚）

根行的每个直接子项 = 一列（**20px 竖轨除外**——轨是导航特殊子项，不参与
列 identity、不参与锚点/吸收者，固定 20px，见 §4.2）。列的 identity 按以
下优先级推导（每次布局变化后重算）：

1. 列内已有 config 戳 → **identity 永久保持**（防夺锚，v3.1-r2 定稿）：
   原锚离开、或拖入别的一级窗格，都不改变列 identity——拖入的窗格只按
   所在列的限制走；
2. 全新列（无戳）→ 列子树内第一个一级窗格的家乡 region 锚定；
3. 都不满足 → main。

**分栏的宽度限制 = 它所在列的限制**（"标签要知道自己被拖进哪一栏"）：
拖进哪栏就继承哪栏；拖回家后限制自动变回来。config 里的 region 是**推导
结果**（跟随状态重钉），不是永久身份。

### 2.2 各列宽度限制（v4.0：只保留最小宽）

| 大栏 | 单分栏最小宽 | 最大宽 | 默认宽 |
|------|--------|--------|--------|
| 左栏 | 240 | **无上限** | 350 |
| 主栏 | 395 | **无上限（吸收一切富余与亏空）** | 746 |
| 右栏 | 240 | **无上限** | 700 |

**v4.0 定稿（用户）**：所有栏**只保留最小宽度限制，最大宽度不限制**——
列能被拖多宽只受窗口物理宽约束。因 max 而生的配套逻辑（聚合 max、无主
栏放开规则、拖拽 max 钳制、rowfix 聚合修正）全部废除。唯一例外：**20px
竖轨 min=max=20 固定**（§4.2——它是导航特殊子项，不是"栏"）。240 是
"单个分栏"的底线；列级 min 按 §2.3 聚合（并排时整列 min = Σ，多分栏时
整列可超 240，单分栏不破 240）。**旧存档里的 maxWidth 由 sync 开机统一
冲开为无上限（99999）**，无需迁移。默认宽 700 指右栏默认结构（检查|文件
并排 + 终端）下的宽度。

### 2.3 列的最小宽按**聚合**计算

一列的最小宽 = 内部分栏 min 的**最大值**（并排取 Σ，含分隔缝）。实现见
`widthBounds`/`heightBounds`（v4.0 起 max 侧聚合只服务轨的 20 固定，
"栏"恒为无上限）。

### 2.4 富余的分配：吸收者唯一（v4.0 简化）

v3.1 的"无主栏时非主栏 max 放开"规则随 max 废除而消失——所有列本来就
无上限，无需放开。富余的**分配**仍按 §9 的唯一吸收者原则执行：主栏 →
（无主栏时）非轨列兜底（配重与 absorb 两个通道各自内部一致），不会多列
随机分——sync 与 absorb 不互相覆盖。

### 2.5 过承诺缩让

Σ(各列聚合最小宽) > 可用宽时（多开主栏分栏或窗口变窄），**主栏分栏的
min 按比例缩让**（底线 40px），宽度恢复后自动回 395。左右栏**每个分栏**
240 底线不让（并排时整列 min = Σ，可超 240；缩让按分栏逐个进行）。
**主栏不在场时无缩让对象——明确接受溢出**（左右栏 240 底线不让，物理
极限，见 §12）。

### 2.6 自适应窗宽（突破 1800）

Σ(各列聚合最小宽) + 轨 + 缝 + 壳边框 > 当前窗宽（装不下/约束溢出）→
**窗宽自动长到 need**（钳到屏幕可用宽与 600 下限；高度不变）——"软件从
1800 变为自适应宽度"。列关闭/合并后 need ≤ 1800 → **窗宽回到 1800 设计
宽**。规则：仅 Tauri 生效（纯浏览器跳过）；窄屏抽屉模式不参与；生长/回
位**仅结构动作触发**——手动缩窗不走撑回，走挤压级联（§9：挤到 min →
合并分栏 → 隐藏左右栏，下限 600 = tauri.conf minWidth，高度 min 600 上
不限）。

## 3. 分栏规则（大栏内部）

| 操作 | 宽度约束 | 高度约束 |
|------|----------|----------|
| **左右分栏**（并排） | 每栏继承所在列的限制 | — |
| **底部加分栏**（上下堆叠） | **顶部第一个分栏保留列限制**；其余跟随上部（不设自己的宽限） | 最小 = 只保留标题栏；最大无限制 |

- 页签默认堆叠；把页签拖出 = 并列新分栏（每栏按上表继承）。
- **链式分裂**（用户 2026-09-26 定稿）：在分裂出的新分栏边缘再分裂，新栏
  仍归属同一大栏——"左栏中有了三个栏"（邻居继承保证：每次分裂的新列从
  其相邻列继承 identity）。
- 堆叠列的聚合 min 由"顶部首分栏 + 柔性子项"共同决定，整列底线不丢
  （v3.1 修正：此前堆叠子项一律清成无界，整列限制丢失）。**细节**：柔性
  子项（无宽限的堆叠分栏）只跟随列宽、**不撑大也不钉死列宽**；列 min =
  MAX(顶部首分栏 min, 柔性子项自身 min)；max 无上限（v4.0）。

## 4. 页签条双形态

### 4.1 横向形态（默认）

- 每个分栏顶部有自己的横向页签条（28px）；单页签分栏的页签**拉伸充满整条**
  （SingleTabStretch）——**这条头栏就是页签本身，拖它 = 拖该页签**。
- **页签 = 纯文字**（2026-09-27 用户定稿：文字就是按钮，点击效果=文字
  颜色，不要按钮形式）：无表面、无下划线、无页签间分隔线、无条底灰线；
  常规 #242424 / hover 品牌色 / 选中 #006fff；多选仍用 accent 14% 洗。
- **页签分隔圆点**（2026-09-27）：横向**多页签条**的相邻页签之间渲染
  5px #BFC3CC 圆点（--tab-dot-size/--tab-dot-color，onRenderTab 对非
  首签注入 leading、CSS 绝对定位骑交界对文字中线）；单页签 zone 与
  折叠轨道无。
- **关闭/回家钮统一**（2026-09-27）：同一图标（CloseIcon，原生 trailing
  经 icons.close 注入）、同一令牌（--tab-close-size/hit/color/
  color-hover，类 fl-close-btn）、**仅悬停所在页签才显形**（含选中页签
  ——flexlayout 默认选中页签 ✕ 常显已压制；撤销此前"离家 ✕ 常显"）。
- **条内左对齐**：logo 带（.flexlayout__tabset_leading 包裹层）绝对定位
  在条顶（满宽、pointer-events none），页签行不再被它顶右——容器
  padding-left 10 + 页签 padding 10，文字与 logo 同一左线（20）。
- **条高双档**（2026-09-27）：顶带分栏（沿父链全为"VERT 行第一孩子"直到
  根行，HORZ 行孩子并排全体算）条高 = --logo-strip-h（100，双重身份 =
  标题栏拖拽区/窗口按钮让位，上部留 logo/文字位）；**非顶带分栏**（上下
  分栏中位于下方的，如终端）条降为 --strip-low-height（36，文字居中，
  无 logo 位）——sync 打 classNameTabStrip 'fl-strip-low'，CSS 落地。
- **主区调色层**（MainTint）：颜色/圆角走令牌 --main-tint-color /
  --main-tint-radius(40)；**垫在窗格文字组件下面**（z -1 + 宿主
  isolation，flexlayout 背景全透明从后面透出）；顶部避开 100 页签带
  （calc + --logo-strip-h，横/竖轨两形态都避）。
- 一级栏的分栏条尾有 [+]（§6）；条尾另有 [切竖轨] 图标。

### 4.2 竖轨形态

**不变式**：竖轨只改变页签轨道的位置与形状，分栏并排结构、宽度限制、内容
全部不动：

1. 该栏全部分栏的横向条隐藏，内容向上充满；
2. **一条 20px 竖轨**出现在该栏外缘（左栏左缘 / 主栏左缘 / 右栏右缘），
   占真实布局空间；**全应用最多三条**（每大栏至多一条，切换 = 建/拆轨，
   不累积）。**轨的特殊地位**：它是根行特殊子项，不参与列 identity
   （§2.1）、不参与回家/重建锚点（§5）、不参与富余吸收（§9）；固定
   20px；**区内最后一个分栏消失时轨一并拆除**（2026-09-27 用户实测
   推翻"空轨保留"——区的回种走回家/拖缘/+，不依赖空轨）；轨的 config
   带 track:true，sync 一律跳过对轨的 config 重钉；
3. 竖轨 = 该栏全部分栏的全部页签清单（按分栏分组，相邻组一条分割线）：
   - 点行 = 激活该页签（所在分栏显示它，页签常驻轨里，宽度限制不动）；
   - 行纵向拖 = 同分栏重排 / 跨分栏搬移；行横向拖出 = 搬去别的大栏；
   - 行下关闭图标（离家一级 = 回家钮）；
4. 顶部一个切换钮（整栏切回横向）；底部 [+]（堆叠进该栏一级分栏，§6）；
5. **会话分栏的 logo 带**（logo 是 sessions 窗格的附属物）：竖轨形态横向
   条隐藏后，工厂在会话分栏**内容顶部**渲染同一条 logo 带
   （.rail-pane-railform > .rail-logo-leading，与横向条 leading 同一组件
   ——同一分栏两形态一个 logo，不双显）；
6. 轨是导航空轨：**不是投放目标**（拖签进轨被拒；贴轨分裂/插入被拒）；
   **空轨态 [+] 可用**——按轨的家乡 region 开窗格，新窗格归属该列（列
   identity 按 §2.1 规则处理）。

## 5. 一级栏与关闭/回家

| 大栏 | 一级窗格 | 规则 |
|------|----------|------|
| 左栏 | 会话列表 | 一级，不可关闭 |
| 主栏 | 主会话 | 一级，不可关闭 |
| 右栏 | 文件树 | 一级，不可关闭 |

- 一级窗格**离家**（不在家乡列）时：页签 ✕ 点击 = **回家**（不是关闭）。
  显形规则跟随 §4.1（2026-09-27 定稿：仅悬停显形——本节早期的"离家 ✕ 常显"
  已撤销，实现跟随 §4.1）。Ctrl+Delete / 关闭手势对一级窗格同样被拦截为回家
  或无效（永不真关闭）。
- **回家锚点**（"主栏就是中间栏"；候选一律**排除竖轨**，并按回退链取）：
  - 左栏窗格 → 根行**最左非轨子项**的左缘；
  - 右栏窗格 → 根行**最右非轨子项**的右缘；
  - 主栏窗格 → 回退链：①最后一个左栏子项（列 identity = left 的列）的
    右缘 → ②第一个右栏子项（列 identity = right 的列）的左缘 → ③根行
    第一个非轨子项的左缘。**与右栏是否隐藏/被拖走无关**——主栏的家只由
    "左栏内容在哪结束"决定；左右栏均不存在时主栏贴最左（其余列依次排
    在其后）。
  - 家乡列已不存在（被 tidy）时才走重建；家乡列仍在则并入堆叠。
- 非一级页签的 ✕ = 真关闭；分栏最后一个可关页签关闭后分栏消失（tidy）；
  一级窗格关不掉，其所在列至少保留它。
- 非一级的可关页签在**拉伸头栏**里同样有 ✕（flexlayout 拉伸头栏不渲染
  原生关闭钮，由 onRenderTab 注入）。

## 6. 「+」号系统

| 大栏 | 位置 | 可开窗格 | 规则 |
|------|------|----------|------|
| 左栏 | 一级分栏条尾 | 机器人 | 单例已开 → 消失；全开 → + 隐藏 |
| 主栏 | 主会话分栏条尾 | 会话（多开） | 堆叠新会话页签 |
| 右栏 | 文件树分栏条尾 | 检查（单例）、终端（多开） | 多种可开 → 弹选择菜单 |

- 竖轨形态下 + 在竖轨底部，语义相同：**堆叠进该栏一级分栏**（同类型收进
  页签组，轨内多行点行切换；要并列就拖出去）。
- 分出的其他栏没有 + 号。**+ 绑定"承载家乡一级窗格的分栏"**：一级窗格离
  家期间，其家乡大栏没有一级分栏（或一级分栏里没有它）→ 该栏不显示 +；
  回家后恢复。

## 8. 快捷键、浮动窗口与键盘删除

- 浮动窗口（Q6）：flexlayout 原生 float，页签悬停出浮动图标，已开启。
  **浮动不改变窗格的家乡身份**（列 identity 由 config 戳与剩余内容承担）。
  **浮动窗格的 ✕ = 取消浮动、回到关闭前位置**（flexlayout 原生行为）——
  不触发"回家"；回家只走页签的回家钮或关闭拦截（实现核查项：onAction
  对浮动窗格的 DELETE_TAB 须放行原生行为，见 §12 待跟进）。
- **键盘删除**：Ctrl+Delete / 关闭手势对一级窗格被 onAction 拦截——离家
  = 回家，在家 = 无效（永不真关闭，与 ✕ 同语义）。
- 快捷键（Q7）：现有 Ctrl+\ 镜像、Ctrl+Shift+\ 布局编辑模式；"拖拽功能
  开关 / 全局横竖轨切换"尚未实现。
- flexlayout 原生键位（页签持焦点）：Ctrl+Delete 关闭、F2 改名。

## 9. 根行不变式（无空白 / 无越界）

根行任何时刻满足：**Σ(各列实际 px) + Σ(竖轨 20px) + 分隔缝 = 可用宽**。
列 min 仅指**列内容宽**（不含轨）；所有量测、配重、拖拽钳制都用这本
总账。三层保证：

1. **flexlayout 原生**：行/分栏内联 min（行的 min 是子节点聚合值）；
   分隔条拖拽按调整行的直接子项 min 钳位（v4.0：max 侧无上限，原生无钳
   可言）。
2. **约束引擎 sync**：过承诺时主栏 min 缩让（§2.5）；分栏限制跟随所在列
   （§2.1）；**maxWidth 统一冲开为 99999**（旧存档残留的 420 等上限在此
   自愈）。
3. **富余兜底 absorbSurplus**（常跑钳制 + 再分配，**吸收者唯一**）：非吸
   收者钳到不低于聚合 min，差额全部交给吸收者——主栏分栏；无主栏 → 非
   轨列兜底（§2.4）。写入权重与渲染真相对齐，消掉 flexbox 钉住态。

4. **拖拽实时钳制（min 侧保险网）**：flexlayout 的 calculateSplit 按 MIN
   侧钳位；嵌套行的 min 不向上传播（原生只钳直接子项）——onAction 对
   ADJUST_WEIGHTS（含 adjusting 中间帧）逐子项钳到不低于聚合 min。
5. **提交帧所见即所得**：flexlayout 的非 adjusting 提交帧会以不同内部状
   态重算权重，把拖好的列砸回 min（逐帧日志实锤）——onAction 记录最后一
   帧 adjusting 权重，提交帧改用之（所见即所得）。
6. **拖拽进行中推迟重排**：sync 的重渲会重置拖拽中的 DOM 权重，下一帧以
   重置后尺寸为新基线、逐帧复利放大——分隔条拖拽进行中，串行重排推迟到
   pointerup 之后执行。

**量测与时机教训**：

- 行节点没有 data-layout-path；量测一律用 **getRect()**（flexlayout 布局
  时维护，与拖拽界限同源，无需查 DOM）。
- **可用宽口径**：宿主 clientWidth − 可见左右**边框轨条**（border 折叠
  轨；innerWidth 会多算）。树内 20px 竖轨是根行子项，**计入 Σ**——两者
  是不同的东西，不得重复扣减。
- **布局未就绪守卫**：flexlayout 要到首次布局才算 calculatedMin/Max
  （fromJson 后全 0）——量不到（px≤0 或 bounds 非有限）时量测/配
  重整体放弃；boot 自愈延后到双 rAF。
- 触发时机：拖拽/结构动作提交后、boot（双 rAF）、resize——全部走**单一
  串行重排通道**（scheduleRebalance：90ms 防抖，固定顺序 量测 → sync →
  absorb，后到取消先到；卸载时取消并作废 model 引用）。多路并发
  setTimeout 已废除（互相覆盖 = 权重向 min 漂移并持久化）。
- **已知待跟进**：极端序列下权重仍可能向 min 漂移并持久化（记忆随
  钳制态被覆盖）；后续加漂移检测 + fullReset 清空全部记忆。

## 10. 拖拽与手柄

- 页签拖拽由 pointer-capture 引擎接管（4px 阈值、rAF 合帧、ghost chip、
  Esc 顶层中止、落点才提交）；多页签块整组拖移。
- **页签条本体拖拽关闭**（2026-09-27 用户定稿：和标题栏打架，只允许
  条内页签可拖）：flexlayout 的 tabstrip 容器 `draggable=true`，空白处
  按住拖 = 整栏拖出/浮动——document 捕获段拦 dragstart，目标不在页签
  按钮内（tab_button / border_button / tab_button_stretch）一律
  preventDefault+stopPropagation（拉伸头栏是页签本身，放行）。页签按钮
  的拖拽由 pointer 引擎接管，原生 dragstart 本就不会发起。
- **拉伸头栏 = 页签本身**：拖它 = 拖该页签（单页签分栏随页签走），属规格
  行为。
- **无边框窗 resize 手柄**（Tauri startResizeDragging，需
  allow-start-resize-dragging）：四边 6px 命中带 + 四角 16px；**四边
  离角 50**（圆角 50px 区域让位，用户 2026-09-27 定稿），状态栏内容同
  规避（左右 padding 50）。
- **拖拽幽灵线**（flexlayout__splitter_drag）是库内非实时模式的遗留指示
  物；本方案为实时缩放 + 实时钳制，它只会误导——CSS **visibility:hidden**
  隐藏（**绝不能 display:none**：flexlayout 拖拽以幽灵线的 offsetLeft/
  offsetTop 为位置输入，display:none 让 offset 变 0 → 每帧按"缝在最左"
  重算，拖动全失效只会跳；2026-09-26 实测）。
- **双击分隔条** = 所属 split 回默认权重：恢复算法 = 预设原始权重**直接
  作为比例**写到该 split 的非轨子项上（轨 20px 固定不参与；flexlayout
  权重是相对值，剩余宽自动按比例分配），逐节点写、之后走串行重排
  （量测 → sync → absorb 兜底钳制）。优先恢复已应用预设树的原始权重；
  用户新开的分叉 → 均分。检测挂 document 原生捕获段，且为**两次点击**
  状态机（按下→拖动→松手是拖拽，不算点击；两次未拖动的点击且间距
  <450ms/10px 才是双击）——否则快速连续拖动会被误判吞掉（2026-09-26
  实测）。恢复时轨按 20px 固定、
  不参与比例；恢复后自然走串行重排（量测 → sync → absorb）。

## 11. 实现载体与技术记录

- 分栏 = flexlayout tabset；页签 = tab；约束载体 = tabset.config
  `{region, rail, track?}`（随布局 JSON 持久化）。**updateNodeAttributes
  的 config 是整对象替换**——重钉 config 会抹掉 track 身份，sync 对轨
  一律跳过 config 重钉（轨身份丢失 = 切轨累积多条 20px 轨，2026-09-26
  实测）。
- 存储键 `mirach.harness.layout.v6`（v4/v5 作废）。**旧键加载策略**：不
  迁移、不解析——直接忽略，首次进入为默认布局（旧键可能含废弃结构，迁
  移会带回 identity 错乱）。
- 拉伸头栏条尾的 [+]、[切竖轨]、注入的 ✕/回家钮绘制在拉伸页签**之上**
  （DOM 序在后），可正常点击；页签文字过长时按钮优先（文字省略）。
- 竖轨载体 = 树内原生 20px 轨 tabset（enableDeleteWhenEmpty:false）；
  工厂对它渲染整栏页签导航 RailNav；分栏横向条 enableTabStrip:false。
- 根行配重 `applyRootWeights`：轨 20 固定、非主栏钉记忆宽（不低于聚合
  min）、主栏按权重分吃剩余。三个坑：adjustWeights 数组映射会写错兄弟
  （逐节点 updateNodeAttributes 替代）；row 节点不保留 config（行身份下
  钻子树）；配重读实际生效 min（v4.0：max 侧不再读）。
- 行的聚合 min：flexlayout 首次布局后才计算（fromJson 后全 0）——
  一切量测/配重必须有就绪守卫。
- **flexlayout-rowfix.ts 已删除（v4.0）**：它只修上游 `calcMinMaxSize`
  的沿轴 max 聚合污染（从 DefaultMax 起算）——max 上限废除后该缺陷无害
  （聚合上限恒 ≥99999 = 无钳），polyfill 连同其 3 个单测一并移除。升级
  flexlayout 不再需要核对此项。
- 已废弃方案（勿回退）：吸收区空分栏、停车轨（点行开栏）、宿主浮层竖轨、
  每分栏一条竖轨、快照式竖轨还原。
